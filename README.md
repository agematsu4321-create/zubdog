# ZUBDOG

ハンドメイドアクセサリー向けのフルスタックECサイトです。

通常商品の購入機能に加えて、デザイン・天然石・数量・要望を指定できるオーダーメイド注文システムを実装しています。

現在開発中で、2026年12月の一般公開を予定しています。

---

## 開発目的

一般的なECサイトの機能に加えて、

「オーダーメイド商品の制作状況を、販売者と購入者の両方がWeb上で確認できる仕組み」

を作ることを目的として開発しています。

オーダーメイド商品では、

注文  
→ 制作  
→ 完成写真の確認  
→ 修正依頼  
→ 再確認  
→ 発送

という通常の商品販売とは異なる流れが必要になります。

ZUBDOGでは、この一連の流れをECサイト内で完結できるように設計しています。

## 主な機能

### ユーザー向け

- 商品一覧表示
- カテゴリ別商品表示
- 商品詳細ページ
- ショッピングカート
- ユーザー登録 / ログイン
- Stripeによる決済
- 注文履歴の確認
- 発送状況の確認
- 追跡番号の表示

### オーダーメイド注文

- デザイン選択
- 天然石選択
- 数量指定
- 要望入力
- 注文内容に応じた価格計算
- オーダーメイド商品の決済
- 完成写真の確認
- 完成品の承認
- 修正依頼
- 修正版の再確認
- 発送状況・追跡番号確認

### 管理者向け

- 商品登録
- 商品編集
- 注文管理
- オーダーメイド注文管理
- 制作ステータス管理
- 完成写真アップロード
- 修正依頼確認
- 修正版写真登録
- 発送処理
- 追跡番号登録
- 顧客へのメール通知
